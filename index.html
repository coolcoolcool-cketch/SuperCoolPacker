SuperCool Packer

Упаковщик Unity-игр в один EXE-файл. Собирает игру вместе со всеми файлами и запускает её прямо из одного исполняемого файла.

Проверка CRC32

При распаковке содержимое файлов проверяется по CRC32.

💻

MSVC

Исполняемый загрузчик собирается при помощи Microsoft Visual C++.

🗂️

Unity

Упаковщик автоматически ищет папку *_Data и главный EXE игры.

🔧

Собственный формат

Архив использует собственный формат SCPK и footer SCPFTR01.

Как это работает?

SuperCool Packer создаёт C++-stub, собирает архив игры и объединяет их в один EXE.

[ C++ STUB ]
[ SCPK ARCHIVE ]
[ SCPFTR01 FOOTER ]

При запуске EXE определяет расположение архива, распаковывает файлы во временную папку и запускает главный EXE игры.
